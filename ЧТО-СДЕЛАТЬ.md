# Как делать мультик из видео с говорящей головой

Что получится: из обычного ролика, где ты говоришь в камеру, выходит вертикальный Reels 1080×1920. В нём:

- **Лица нет.** Звучит твой настоящий голос, очищенный от шума.
- **Весь экран — анимация по смыслу фраз:** сцены на 3–6 секунд, персонажи с мордочками, схемы, графики, «мир» с облаками, солнцем и холмами.
- **Твои фото — стикерами.** Фигура вырезана с фона, у неё белая обводка и тень. Она появляется 4–5 раз там, где уместен «рассказчик».
- **Субтитры** — жирным капсом внизу, слова всплывают в момент произнесения.

Всё это делает Claude Code по промту из `ПРОМТ.md`. Ты даёшь видео и фото, он собирает ролик и сам его проверяет.

## 1. Один раз: что поставить

1. **Claude Code** — claude.com/claude-code (приложение или CLI).
2. **Python 3.11–3.12** и **ffmpeg** (с ffprobe) в PATH.
3. Пакеты Python:
   ```
   pip install numpy pillow opencv-python
   ```
4. **DeepFilterNet** — нейросетевой шумодав. Скачай готовую программу `deep-filter` под свою систему со страницы релизов github.com/Rikorose/DeepFilterNet (Windows — `deep-filter.exe`, macOS/Linux — бинарник). Путь к ней пропиши в `build/voicefx_v3.py`, строка `DF = …`. Claude сделает это сам, если скажешь, куда положил.
5. **rembg** — вырезает фигуру с фото. Лучше поставить в отдельное окружение:
   ```
   python -m venv rembg-venv
   rembg-venv/bin/pip install "rembg[cpu]"
   ```
   На Windows вместо `rembg-venv/bin/pip` будет `rembg-venv\Scripts\pip`. Модель `isnet-general-use.onnx` (~180 МБ) rembg скачает сам. Если скачивание падает, возьми её curl-ом с github.com/danielgatis/rembg/releases и положи в папку из переменной `U2NET_HOME`.
6. **Расшифровка с таймингами слов.** Нужен один из двух вариантов:
   - ключ OpenAI в файле `build/.env` строкой `OPENAI_API_KEY=…` — whisper-1 для таймингов и gpt-4o-transcribe для сверки текста;
   - или локально `pip install faster-whisper` — Claude перепишет `align18.py` под него.
7. **Шрифт** Unbounded Black уже лежит в `build/fonts/`. Это открытая лицензия OFL. На macOS можно взять SF Pro Expanded Black.

## 2. На каждый ролик

1. Положи рядом с этой папкой:
   - видео с говорящей головой, вертикальное, лучше 1080×1920 или 720×1280;
   - папку со своими фото: 5–10 штук, по пояс или в полный рост, лучше на однотонном фоне;
   - трек для фона (mp3) — спокойный, без вокала, с лицензией для Reels.
2. Открой Claude Code в этой папке.
3. Вставь промт из `ПРОМТ.md`, подставив три пути вверху.
4. Дальше он работает сам:
   - покажет 6–8 пробных кадров;
   - отрендерит весь ролик (на обычном ноутбуке это ~1,5–2 с на кадр, то есть 30–40 минут на 45-секундный ролик);
   - прогонит проверки и отдаст mp4 и контакт-лист.
5. Правки проси словами: «сцена про X пустая — крупнее», «убери звук Y», «фото в финале другое». Он перерисует только нужные сцены, а не весь ролик.

## 3. Что внутри папки

| файл | что это |
|---|---|
| `build/cartoon18.py` | **главный образец** — движок мультика: кисть в двойном разрешении, персонажи, мост, поезд, доска, стикеры из фото, аватарка, 12 сцен ролика «треугольник держит мост» |
| `build/cartoon19_образец_футбол.py` | второй образец — 17 сцен футбольного ролика (поле, игроки, скаут, угол на ворота, кубки) |
| `build/sfx18m.py` | звук мультика: голос + музыка + мягкие «вжухи» на сменах сцен → мастер |
| `build/qa18m.py` | проверки: рисунок не заходит на субтитры, все символы есть в шрифте, математика, громкость |
| `build/voicefx_v6.py` (+ v3, v5) | очистка голоса DeepFilterNet — **это стандарт** |
| `build/voicefx_v7.py` | VoiceFixer — **не использовать**: голос звучит как робот. Оставлен только потому, что его импортирует `sfx18.py` |
| `build/master_v2.py` | мастер громкости: −14 LUFS, пик ≤ −1 dBTP, с перепроверкой |
| `build/captions.py`, `render18.py`, `storyboard18.py`, `style.py`, `win_fonts.py` | субтитры v3 и акценты (прыжок слова, подчёркивание маркером, штамп) |
| `build/align18.py`, `snap18.py` | расшифровка и подгонка границ слов по звуку |
| `videos/18/words*.json` | пример расшифровки с таймингами — чтобы образец запускался |
| `ПРАВИЛА-мультик.md` | все правила, выработанные на наших роликах: что проверено и почему |
| `примеры/кадры-мультика-15.2.jpg` | как это выглядит |

Готовые ролики-примеры (15.3 «треугольник держит мост» и 16.4 «футбольная аналитика») автор пришлёт отдельно.
